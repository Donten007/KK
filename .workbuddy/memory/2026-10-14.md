### 技术底座调研结论
| 层 | EvoFlow | 我们的方案 |
|----|---------|-----------|
| 桌面端 | Tauri + React + Vite | Tauri 2 + React（可借鉴） |
| Agent 内核 | LangGraph | LangGraph（事实标准） |
| 后端 | FastAPI + SSE | FastAPI（长任务必需 SSE） |
| 存储 | **SQLite 单文件** | ❌ 必须换 **PostgreSQL**（SaaS 多租户撑不住） |
| 沙箱 | 默认本地沙箱（自认安全性最低） | ❌ 必须**强制容器隔离 + 默认禁网 + 四重限额** |
| 认证 | webui 包 JWT/OIDC，桌面设备绑定 | 真正的多租户 SaaS 账号体系（它的治理层在开源版残缺） |

### 发现的差异化机会
- EvoFlow 开源版治理层（多账号/SSO/费用统计/安全中心）**残缺**，因为它是桌面应用 → 这是我们的空白机会
- 它的「资源包」`evoflow.organization.json` 机制可改造成**模板市场**（技能包/ 方案模板 / 团队模板三层），这是卖钱主路径
- 思维导图系统（证据驱动，`claim:` 必须挂 `file:`/`gap:` 证据节点）是差异化杀手锏
